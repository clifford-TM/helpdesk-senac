# HelpDesk Senac

Projeto desenvolvido para o Projeto Integrador do curso Técnico em Desenvolvimento de Sistemas do SENAC.

## Objetivo

O sistema HelpDesk tem como objetivo permitir o registro e o acompanhamento de chamados de suporte técnico.

## Funcionalidades atuais

- Cadastro de usuários
- Abertura de chamados
- Definição de categoria e prioridade
- Atribuição de técnico
- Alteração de status do chamado
- Conclusão de chamados
- Listagem de chamados

## Organização do projeto

O projeto foi estruturado em camadas:

- `model`: representa as entidades do sistema
- `repository`: responsável pelo armazenamento e consulta dos dados
- `service`: concentra as regras de negócio
- `HelpDesk.java`: contém testes executados pelo método `main()`

## Tecnologias

- Java
- Maven
- NetBeans
- Git e GitHub
